# R4：搜尋關鍵字自動分類規則與範例（收購類 / 商品類 / 內容類）

## 重點結論（三行摘要）
1. **採用「雙重信號（字詞關鍵字 + 對應頁面網址）」優先序規則**：先檢查查詢字詞（`query`）是否命中高意圖關鍵字，若字詞本身僅有型號（如 `iphone 16 pro 256g`），則用對應曝光頁面（`page`）的網址路徑（`/pages/.*收購`、`/products/`、`/blogs/`）輔助判定，最後才歸入預設類別。
2. **嚴格的分類優先順序為「收購類 ➔ 內容類 ➔ 商品類」**：因為「收購類」關鍵字常同時包含機型與「二手/價格」字眼（如 `二手 iphone 15 收購價`），必須優先攔截 `收購 / 回收 / 賣 / 估價 / 舊換新`；接著攔截教學與評測類字詞（`怎麼 / 教學 / 比較 / 發表`）歸為「內容類」；其餘帶購買意圖、配件或純產品型號的字詞歸為「商品類」。
3. **規則透明且易於在 `opportunities.py` 實作與測試**：全套規則僅需標準字串比對（統一轉小寫、去除多餘空白），零外部 API 成本、執行速度極快，且未來第二版可無縫切換為 AI 分類。

---

## 一、為什麼要分這三類？（給新手的背景說明）

當消費者在 Google 搜尋並看到「炘馳通訊」時，他們心裡想做的事主要有三種（對應 SPEC.md 的三大目標）：
1. **想把舊手機賣給我們換現金（收購類）**：例如搜「台中二手手機收購」、「iPhone 15 Pro 回收價」。這類客人需要看到**公開透明的收購價目表與門市LINE估價入口**。
2. **想跟我們買二手機、新機或配件（商品類）**：例如搜「iPhone 14 Pro 二手 空機」、「台中買二手機推薦」、「iPhone 17 保護貼」。這類客人需要看到**有現貨、標價清楚的商品頁或分類頁**。
3. **遇到手機問題想查解答或看新機資訊（內容類）**：例如搜「LINE 偷看訊息不已讀」、「iPhone 電池健康度掉很快」、「Apple TV 4K 規格」。這類客人進來讀部落格文章，可以幫我們**衝高全站流量、累積品牌信任感與 AI 引用率**。

把 Search Console 抓下來的關鍵字自動分成這三類，我們在看儀表板和週報時，就能一眼看出：「這個字詞應該拿去改**收購頁**、改**商品分類頁**，還是寫一篇新的**部落格文章**？」

## 二、分類判定邏輯與優先順序（給工程師 C4 `opportunities.py` 實作規格）

### 1. 前處理（Normalization）
在比對前，先將 `query` 統一做正規化：
- 轉為全小寫：`q = query.strip().lower()`
- 全形英數轉半形（或直接比對常見英數字元）

### 2. 三階段優先判定流程（Priority Order）

> [!IMPORTANT]
> **為什麼順序很重要？**
> 假設消費者搜尋 `"iphone 15 pro 二手收購價格"`，裡面同時有 `"二手"`、`"價格"`（看似商品類），也有 `"收購"`（收購類）。因此程式必須**先檢查是不是「收購類」**，不是才往下檢查「內容類」與「商品類」。

#### 第一優先：判定為「收購類」（Buyback / Trade-in）
只要符合以下任一條件，即歸類為 `收購類`：
- **字詞命中收購核心詞**：
  `收購`、`回收`、`估價`、`賣手機`、`賣二手`、`手機換現金`、`二手機買賣`（偏雙向但高收購意圖）、`舊換新`、`舊機換新機`、`折抵`、`貼換`、`收機`、`哪裡可以賣`、`能賣多少`、`可以賣多少`、`殘值`、`收購價`、`回收價`、`收購表`
- **字詞為純機型/模糊詞，但對應頁面（`page`）是收購頁**：
  若字詞未命中內容類或明確購買詞，且 `page` 網址包含 `/pages/` 並帶有 `收購`、`phone-valuation` 或屬於 Sitemap 中的單機收購價目頁（如 `/pages/16-pro-256g`）。

#### 第二優先：判定為「內容類」（Content / Informational）
若不屬於收購類，且符合以下任一條件，即歸類為 `內容類`：
- **字詞命中疑問、教學、故障排除或資訊詞**：
  `怎麼`、`如何`、`為什麼`、`教學`、`方法`、`設定`、`解決`、`無法`、`打不開`、`耗電`、`發燙`、`當機`、`黑屏`、`備份`、`轉移`、`不已讀`、`偷看`、`隱藏`、`技巧`、`懶人包`、`是什麼`、`意思`、`差別`、`比較`、`好嗎`、`值得買嗎`、`評價`、`評測`、`開箱`、`發表`、`上市時間`、`亮點`、`更新`、`災情`、`規格比較`、`電池健康度`（除非帶有「買/價格」）
- **字詞未帶明確買賣詞，且對應頁面（`page`）是部落格文章**：
  `page` 網址包含 `/blogs/`。

#### 第三優先：判定為「商品類」（Product / Commercial & Transactional）
若不屬於上述兩類，或符合以下條件，即歸類為 `商品類`：
- **字詞命中購買、價格、二手機選購或配件詞**：
  `買`、`購買`、`哪裡買`、`推薦`、`空機`、`現貨`、`售價`、`價格`、`多少錢`、`便宜`、`特價`、`促銷`、`福利機`、`福利品`、`中古機`、`二手機`、`二手 iphone`、`二手 ipad`、`保護貼`、`玻璃貼`、`鏡頭貼`、`手機殼`、`防摔殼`、`充電線`、`傳輸線`、`充電器`、`快充`、`行動電源`、`耳機`、`免運`、`保固`
- **字詞為純產品/品牌/型號/門市名稱**（預設商業意圖）：
  例如單搜 `iphone 16 pro max 256g`、`ipad mini 7`、`台中通訊行`、`北屯通訊行`、`炘馳通訊`，或對應頁面為 `/products/`、`/collections/`、`/categories/`。

```python
from typing import Literal

KeywordCategory = Literal["收購類", "商品類", "內容類"]

def classify_keyword(query: str, page_url: str = "") -> KeywordCategory:
    """根據查詢字詞與對應網址，將關鍵字自動分類為「收購類」、「商品類」或「內容類」。"""
    ...
```

這樣無論只傳 `query`，或是同時傳入 `query` 與 `page_url`，都能穩定回傳三種分類之一。
