# 給 Claude Code 的規則

你是這個專案的**主力工程師**。先讀 `規格書.md` 和 `任務清單.md`。

## 團隊
- **使用者**：老闆，最後決定。用繁體中文溝通。
- **網頁版 Claude**：規劃師，寫了規格書和任務清單。規格有疑問時，寫進 `討論.md` 讓使用者帶回去問。
- **agy（Gemini）**：研究員兼審查者。研究結果在 `research/`，實作前先讀相關的研究報告。
- **Jules**：在 GitHub 上接小任務（健檢規則、測試），會開 PR。

## 工作方式
- 只做任務清單上標 🛠 的任務。開始時把狀態改成 `[~]`，完成改成 `[x]`。
- 一次一個任務，每個任務完成就 commit，訊息格式：`C3: 串接 Search Console`
- 規格沒寫清楚的地方，選最簡單的做法，並在 `討論.md` 記一筆說明你的選擇。
- 不要做第二版的功能。

## 程式規範
- Python 3.12，型別註記，函式附繁體中文 docstring
- 金鑰只從 `.env` 讀，絕不寫死在程式裡，絕不 commit `.env` 或 `credentials/`
- 每個模組都要有 pytest 測試；網路呼叫要能 mock，測試不可連真的網站
- 健檢規則放 `src/seo_radar/checks/`，一條規則一個檔案，介面統一（見 C6）

## 跟 agy 配合
- 需要讀大量資料或查資料時，可以請使用者轉給 agy，或在 `討論.md` 留下問題。
- agy 的審查意見會寫在 `討論.md`，處理後在該條下方回覆「已修正」或「不採納，原因：…」。
